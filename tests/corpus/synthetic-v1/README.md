# 合成レポート コーパス v1


このディレクトリ内のすべての名前、日付、金額、アカウント、ポリシーの値は、公開テスト用に特別に作成されました。既存の簿記データは、匿名化、変換、サンプリング、またはソース素材として使用されていません。


不変コーパスの演習:


- 複数のアカウントおよび 3 つ以上の投稿を伴うトランザクション。

- 両方の商品を含む 1 つのトランザクションを含む、独立してバランスのとれた円と米ドルの転記。

- 固定された `2026-07-31` 境界時点の前、現在、後のトランザクション。

- 日次フローと月次アカウントの数か月にわたる収入と支出の活動。

- 最近のトランザクションを実行するのに十分な境界付近のトランザクション全体。そして

- CI で使用される同じレポート コントラクトおよびすべて/スタンドアロン エントリポイント チェック。


このバージョン管理されたディレクトリ内のファイルは、その場で編集しないでください。新しい合成コーパス バージョンを作成し、そのコントラクトを変更する必要がある場合にゴールデン観察をレビューします。 `MANIFEST` は正確なパブリック入力を修正します。
